# ROLE

You are a senior UI/UX designer, creative director, visual storyteller, and front-end engineer.

Create a premium **single-page interactive portfolio website** for a student from **Foreign Trade University (FTU), Hanoi**, majoring in **International Economics**.

The portfolio should not feel like a traditional website. Instead, visitors should experience a magical journey inspired by the atmosphere, storytelling, and elegance of **Alice in Wonderland**, while remaining completely original and avoiding any copyrighted characters, artwork, or assets.

The final website should feel immersive, elegant, modern, cinematic, responsive, and professional.

```

```

Requirements:

* Automatically preload the music.
* Due to modern browser restrictions, do **not** autoplay with sound before user interaction.
* Display an elegant music control button in the top-right corner.
* When the visitor clicks **Begin Journey**, start playing the background music automatically.
* Music should loop continuously.
* Volume should default to **30%**.
* Remember the playback state while navigating within the page.
* Add a smooth fade-in (about 2 seconds) when playback starts.
* If the user pauses the music, remember their preference during the session.

Music button states:

* ▶ Play
* ⏸ Pause

Add a subtle hover animation and a glowing effect consistent with the Wonderland theme.
